# Приложение для генерации и чтения PDF документов

Это приложение для генерации и чтения PDF документов на основе SwiftUI, которое позволяет пользователям создавать, редактировать, сохранять и делиться PDF документами. Приложение использует **Realm** для локального хранения данных и **PDFKit** для создания и управления PDF документами.
---

## Функции

- **Экран приветствия**: описание возможностей приложения.
- **Генерация PDF документов**: генерация документов из изображений, выбранных из галереи фотографий.
- **Редактирование PDF документов**: добавление, удаление или изменение порядка страниц в документе. (На доработке)
- **Сохранение PDF документов**: локальное сохранение документов с помощью Realm.
- **Обмен PDF документами**: возможность поделиться документом.
- **Объединение PDF документов**: объединение двух документов в один и его сохранение.
- **Просмотр PDF документов**: просмотр документа в постраничном ридере с предварительным просмотром.
- **Удаление PDF документов**: удаление документа из локального хранилища.

---

## Используемые технологии

- **SwiftUI**: UI framework.
- **Realm**: для локального сохранения данных.
- **PDFKit**: для создания и управления PDF документами.
- **PHPicker**: для выбора изображений из библиотеки фотографий.

## Структура кода

### Models

#### `Document`
Модель документа со следующими свойствами:
- `id`: уникальный идентификатор.
- `name`: имя документа.
- `filePath`: путь к сохраненному файлу.
- `createdAt`: дата создания.
- `thumbnailData`: данные миниатюры изображения.
- `pages`: Список объектов `DocumentPage`.

#### `DocumentPage`
Модель одной страницы в документе со следующими свойствами:
- `id`: Уникальный идентификатор.
- `document`: Ссылка на родительский `Document`.
- `pageIndex`: Индекс страницы.
- `pageData`: Данные изображения для страницы.

---

### Views

#### `DocumentsListView`
Основное View, отображающее список сохраненных документов PDF. Пользователи могут:
- Генерировать новые PDF-файлы.
- Переходить в `DocumentReaderView` для просмотра или редактирования документа.
- Делиться, удалять или объединять документы.

#### `DocumentReaderView`
View для чтения и редактирования документов. Пользователи могут:
- Просматривать страницы в постраничном формате.
- Удалять страницы.
- Сохранять изменения в PDF документе.
- Делиться документом.

#### `DocumentSelectionView`
View для выбора документа для объединения с другим.

#### `WelcomeView`
Экран для начинающих пользователей.

#### `DocumentsListViewCell`
View ячейки для отображения отдельных документов в списке.

---

### ViewModels

#### `DocumentsListViewModel`
Управляет состоянием и логикой для `DocumentsListView`. Основные функции включают:
- Загрузка документов из Realm.
- Создание, сохранение и удаление PDF-файлов.
- Объединение PDF-файлов.
- Обработка выбора изображений и генерация PDF-файлов.

---

### Утилиты

#### `ImagePicker`
Оболочка SwiftUI для `PHPickerViewController` для выбора изображений из библиотеки фотографий.

#### `ActivityView`
Оболочка SwiftUI для `UIActivityViewController` для обмена PDF документов.

## Использование

1. **Создание PDF документа**:
- Нажмите кнопку «Generate PDF».
- Выберите изображения из библиотеки фотографий.
- Введите имя документа.
- Далее откроется экран для чтения и редактирования документов.
- При нажатии на кнопку "Save" сгенерируется документ в формате PDF и сохранится в локальной БД.
- При нажатии на кнопку назад, не нажав на кнопку "Save", документ не будет сохранен.

2. **Редактирование PDF документа**:
- Нажмите на документ в списке, чтобы открыть его.
- При необходимости удалите страницы.
- Нажмите «Save», чтобы сохранить изменения.

3. **Объединить PDF документы**:
- Долго нажмите на документ и выберите «Merge».
- Выберите другой документ для объединения.
- Будет создан новый объединенный PDF документ.

4. **Поделиться PDF документом**:
- Долго нажмите на документ и выберите «Share».
- Выберите, куда отправить документ.

5. **Удалить PDF документ**:
- Долго нажмите на документ и выберите «Delete».

## Известные проблемы

- **Редактирование сразу после создания**: приложение может аварийно завершить работу при попытке редактировать документ сразу после генерации и сохранения, если не выходить из экрана. Это известная проблема, отмеченная в коде как `FIXME`, будет исправлена в скором времени.
